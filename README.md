# Portfolio

Personal portfolio of Umarfarook Gurramkonda, AI/ML engineer.

**Live:** [umarfarook-ai.vercel.app](https://umarfarook-ai.vercel.app)

## Stack

- Next.js 16 / React 19 / TypeScript
- Tailwind CSS 4
- react-three-fiber for the 3D background
- framer-motion for animations

The Selected Results section surfaces measured metrics pulled from my public repos, not made-up numbers.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
